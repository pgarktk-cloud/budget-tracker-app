# Current UI summary

## Structure

The app uses a fixed bottom navigation bar with five user-customizable destinations and a **More** sheet. The default destinations are Home, Budget, Expenses, Banks, and Investments. Additional sections include Net Worth, Goals, Installments, Purchase Advisor, Bills, Household, and Currency. Settings and sync controls sit in the global header.

Most secondary forms and actions open in top-aligned sheets or modal panels. A floating quick-add action provides fast access to transaction entry.

## Current visual language

- Mobile-first card dashboard inside a centered responsive column
- Slate/blue-gray surfaces with navy text and jade-green primary accents
- Supporting blue, muted red, and soft status colors
- Neumorphic content surfaces and translucent glass navigation/overlays
- Serif treatment for prominent financial figures
- Dense use of cards, inline controls, pills, and compact financial data
- Light and dark theme support

## Current strengths

- Broad functionality remains reachable on mobile
- Persistent, customizable navigation supports frequent workflows
- Quick-add and sheets keep common actions close at hand
- Home already uses financial summaries, trend charts, and progress views
- Individual and household perspectives are available across relevant areas

## Redesign opportunities

- Establish a clearer hierarchy across a feature-rich product
- Reduce competition between cards, controls, status messages, and figures
- Make key financial meaning understandable at a glance
- Use visualization more consistently to replace or support raw figures
- Improve continuity between overview screens and detailed workflows
- Reinterpret the experience as a coherent product rather than reskinning the existing components
